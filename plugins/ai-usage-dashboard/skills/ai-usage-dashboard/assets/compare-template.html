Credit จริง vs Subscription

สร้างจาก ccusage · __GEN__

ตั้งค่าราคา subscription (แก้ได้)

“Credit จริง” ในหน้านี้ = ค่า token ที่ ccusage คำนวณที่อัตรา API (ถ้าจ่ายแบบ pay-per-token) ส่วน subscription = ค่าสมาชิกรายเดือนที่คิดตามสัดส่วนจำนวนวันของข้อมูล ราคาเริ่มต้นเป็นค่าสมมติ กรอกราคาจริงที่ได้รับเพื่อให้ผลถูกต้อง

สะสมตามวัน: ค่า API เทียบกับค่าสมาชิก (USD)
